| Removed an operating scope that could only fail | The context switcher offered "All branches", and every `/api/v1` route answered it with a 400 because a request must name one branch. A System Administrator was already being handed every branch beside the unusable row, so nothing was lost. |

| Stopped showing a Wing Van as a tractor-trailer | The photo map pointed "Wing Van" at the curtainsider shot, with a note in the file admitting that was the closest of four supplied photographs rather than a correct one. | Found a backup script that had never reported success | Running it revealed it printed "Dumping…" and then nothing at all.
